🛍️ ShopFlow — E-Commerce Product Catalog

A modern, responsive e-commerce storefront developed for Task 4 of the Datheon AI Systems & Automation Studio Internship.

🌐 Project Links

- Live Demo: https://prajwal21-12.github.io/shopflow/
- GitHub Repository: https://github.com/Prajwal21-12/shopflow

«Note: The live demo link will work after you create the repository, upload the project files, and enable GitHub Pages.»

✨ Features

- 🛒 Dynamic product catalog using FakeStoreAPI
- 🔍 Search products by name
- 🗂️ Filter by Electronics, Jewelry, and Clothing
- ⭐ Product ratings, prices, and images
- ➕ Add products to the shopping cart
- 🔢 Increase and decrease product quantities
- 🗑️ Remove products from the cart
- 💰 Automatic subtotal, tax, shipping, and total calculations
- 💾 Save cart contents using browser localStorage
- ✅ Simulated checkout with order confirmation
- 📱 Responsive design for desktop and mobile
- ⚠️ Loading indicators and API error handling

🚀 Run Locally

1. Clone the repository:
   
   git clone https://github.com/Prajwal21-12/shopflow.git

2. Open the "shopflow" folder in VS Code.

3. Open "index.html" in your browser.

4. Search products, apply category filters, and test the cart and simulated checkout.

An internet connection is required to fetch products from the API.

🔗 API

Product data is provided by FakeStoreAPI:

https://fakestoreapi.com/products

💰 Shopping Cart Calculation

- Subtotal: Sum of each product's price multiplied by its quantity.
- Tax: 5% of the subtotal.
- Shipping: ₹50 for orders below ₹1,000; free shipping for orders of ₹1,000 or more.
- Total: Subtotal + tax + shipping.
